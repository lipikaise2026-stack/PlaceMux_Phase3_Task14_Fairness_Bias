1. Outcome-Disparity Analysis

The framework compares outcome rates across authorized groups using both absolute and relative disparity measures.

Metric Production Value Definition Source Decision
Selection Rate N/A Proportion of eligible users receiving the measured positive outcome. Production outcome and eligibility events Identify differences in outcome rates across groups.
Outcome Rate N/A Proportion of users in each group reaching the defined business outcome. Production outcome events Monitor outcome disparities.
Outcome Rate Ratio N/A Group outcome rate divided by the reference-group outcome rate. Production outcome observations Identify relative disparity requiring investigation.
Absolute Outcome Gap N/A Difference between a group's outcome rate and the reference-group outcome rate. Production outcome observations Quantify the absolute size of observed disparity.

2. Defensible Fairness Methodology

Methodology Area Method Decision / Limitation
Group Definition Use only authorized and appropriately consented group attributes. Privacy, consent and governance review required.
Reference Group Select the reference group before interpreting disparity. Prevents changing the comparison after observing results.
Outcome Definition Define the business outcome using a production event and fixed reporting window. Ensures groups are compared on the same outcome.
Disparity Measurement Calculate both absolute and relative outcome differences. Separates magnitude from relative disparity.
Uncertainty Report confidence intervals or other uncertainty estimates when production observations are available. Avoid treating small-sample differences as reliable effects.
Causal Limitation Observed disparity is not treated as proof of discrimination or causal mechanism. Requires further investigation or controlled testing.
Consent & Proxies Do not infer protected attributes from unrelated behavioural or demographic fields. Protects against unsupported proxy-based conclusions.

4. Causal Interpretation

  • Observed disparity is not treated as proof of causation.
  • Small samples require uncertainty assessment before interpretation.
  • Potential data-quality problems must be investigated before product conclusions.
  • Proxy-based inference of sensitive attributes is not permitted.
  • Potential fairness concerns should be investigated using appropriate controlled analysis.

6. Failure & Edge-Case Handling

  • Missing production data → fairness analysis blocked
  • Missing group attribute → affected comparison blocked
  • Missing outcome event → outcome calculation blocked
  • Insufficient observations → uncertainty remains high
  • Invalid timestamps → invalid observations excluded
  • Source reconciliation failure → production conclusion blocked
  • Unauthorized or inferred sensitive attributes → analysis blocked
